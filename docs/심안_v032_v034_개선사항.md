# 심안 v0.32 ~ v0.34 변경 정리

기획안 `design/improvement-plan-v029.md` §16의 세 묶음(v0.32 스테이지 · v0.33 메타 · v0.34 분량·출시 준비)을 순서대로 구현한 기록입니다.

## v0.32 — 스테이지
- **§6.1 지형 규칙 엔진**: `onLand` · `onDashPath` · `onTick` · `zoneAt` 네 갈래 하나로 1~12장 규칙을 구현.
  - 잔해(2): 잔해 위 착지 0.2초 비틀거림 — 다음 획은 선입력. / 대숲(3): 대숲을 지나는 일섬 0.3초 느려짐, 피해 ×1.3.
  - 월광 주기(4): 20초마다 5초 붉은 달 — 원귀 속도 ×1.2, 처치 엽전 ×2. / 안개 띠(5): 원 반경 10초 주기 ±8%.
  - 눈밭(6): 착지 뒤 0.6m 미끄러짐. / 뿌리(7): 0.4초 묶임 + 착지 충격 2배.
  - 종루(8): 종을 치면 원 밖 원귀가 2초만 드러남(§17 결정 8 — 짧은 순간만). / 혈석(9): 핏빛 바닥 재생, 혈석을 베면 8초 꺼짐.
  - 물길(10): 물길 가로지르는 일섬 길이 −30%, 물 위 원귀 느림. / 성벽 포대(11): 30초마다 화살비(예고 1.2초).
  - 나락 가장자리(12): ~~가장자리에서 0.5m/초 끌림~~ → **2026-11-18 제거** — 검은 구덩이와 끌림이 불필요하다는 판단으로 12장 지형 규칙을 없앴습니다(소개 카드도 '지형 · 없음'). 다른 장 규칙은 그대로입니다.
- 장 소개 카드에 지형 규칙 한 줄(`#stageTerrain`), 발동 횟수는 `S.terrain.counts`와 telemetry `terrain` 이벤트로 기록.
- **§7.1 난이도 곡선**: 표의 예고/무늬/생성간격을 그대로 반영(4·8·12장 정점, 5·9장 숨 돌림). 보스전 시간 예산 Slack 1.4 이상 유지(12장 `bossAt` 186→182).
- **§7.4 별 조건**: 별 2 = 체력 50% 이상 **또는** 피격 3회 이하. 별 3 = 정점 장(4·8·12) 패턴 공략 / 나머지 콤보 0.8배 또는 지형·부목표.
- **§4.4·4.5 막 보스**: 8장 합 겨루기(1.2초·3합)·흉내(0.8초 뒤 궤적 추적), 12장 무늬 뒤섞기(2초마다 변경, 금빛 0.4초 고정)·3페이즈(결계 9m·예고 −10%). 보스 개성: 외형 4벌(머리 장신구 4종·무기 3종), 크기 0.9~1.15배, 등장 이름 카드 1.2초, 도감 기록.

## v0.33 — 메타
- **save v3**: `save.version` 도입, 예전 세이브 자동 이전, 손상 시 `.bak` 백업 복구.
- **무구(검) 5종**(600~1,500): 장 첫 클리어로 도면 해금, 구매·장착. 서릿검(빙결)·화살검(콤보 12 불꽃)·청풍검(일섬 거리 +10%)·귀문검(빈틈 참 +5).
- **유물 12종**: 판 시작 1개(저주 염주면 2개) 장착. 청동 거울·금실 칼집·빈 항아리·혈월 부적·거꾸로 된 탑·안개 바늘·세 번째 눈·기물 장인·늙은 붓·연꽃 등·묵은 방울 모두 실제 규칙에 연결.
- **도감**(귀물 8·보스 12·진화 10·패턴 9): 묶음 완성마다 엽전 +5%, 최대 +20%.
- **외형 6종 / 붓 자국 4종**: 능력 없음(§12 원칙).
- **§8.3 무늬 수련장**: 10종 자유 연습, 무늬별 최근 20회 인식률, 80% 미만이면 붓끝 요령 애니메이션.

## v0.34 — 분량·출시 준비
- **§10 도전 모드**: 무한 심연(8장)·보스 러시(12장)·무늬 시련(4장). 무한 심연은 3분 뒤 보스, 잡으면 90초 뒤 다음; 보스 러시는 열두 보스 연속·체력 유지·보스 사이 카드 1장. 기록 저장.
- **§6.2 장별 부목표**: 5장 석등 수호 / 7장 정예 사냥 / 9장 한 무늬 30초 / 10장 어둠 60초 / 11장 시간 −30%·처치 +0.5초. 별 3과 연결, HUD 한 줄 표시.
- **§6.3 웨이브 3종**(원형·반원 협공·두 줄 행렬)과 **속성 정예**(얼음·분열·방울).
- **§12 수익 방향**: 가짜 광고 버튼 제거, 상점에 "힘을 파는 상품은 없습니다" 명시.
- **§14 성능**: 청크는 창이 밀릴 때 새로 들어오는 한 줄(3청크)만 데이터를 짓고, 배치는 용량을 잡아 둔 버퍼를 재사용해 행렬만 다시 씀(드로우콜 9 유지). 부적 탄 24·장판 12·기둥 6·기물 6 풀 상한.
