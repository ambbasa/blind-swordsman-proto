## 1. 목표와 한 줄 요약

**"한 판이 끝나도 다시 켜고 싶은 게임"** — v0.23에서 그래픽·12장 스테이지 뼈대가 잡혔으니, v0.24는 세 가지를 채운다.

1. **싸움의 격을 올린다** — 보스전을 잡몹 난전에서 **결계 안 1:1 공략전**으로 바꿔, 회피·패링·역공이 하나의 문법이 되게.
2. **손맛을 칼맛으로** — 히트스톱·타격음·먹물을 이벤트별로 재배분하고, 참(斬) 준비 상태를 HUD에서 바로 알아보게.
3. **판 밖에 다음 목표를 둔다** — 첫 10초에 몸으로 익히게 하고, 로비에 무구·유물·도감이라는 수집 목표를 세운다.

## 3. 보스전 1:1 공략 패턴 전면 개편

### 3.1 현행(v0.23) 진단 — 코드 확인 결과

| 요소 | 현행 | 문제 |
|---|---|---|
| 결계 | 보스 등장 시 `openArena`(반경 `CFG.arenaR = 12`) · 필드 잔몹은 `clearFieldForBoss()`로 소거 · 보스 생존 중 일반 스폰·포위 웨이브 중지 | 이미 1:1에 가깝다 |
| 잡몹 | 보스가 **경직이 끝날 때** `STAGES[].boss.adds`만큼 소환(3장 2 → 11·12장 4) | 남은 유일한 난전 요소. 1:1 집중을 깬다 |
| 보스 상태기계 | `walk → telegraph → charge → stun`(`stepBoss`) · 돌진 충돌 `bossDmg = 2` · 예고 0.8~1.35초 · 돌진 16~25 m/s | 패턴이 "돌진 하나"뿐이라 공략할 거리가 없다 |
| 파훼 | **경직 중에 베면 절단 2회**(`cutSpirit`: `s.state === 'stun'` → `seqI++` 두 번, "파훼!") | 이미 있다. 다만 경직을 **플레이어가 능동적으로 만들 수단이 없다** |
| 패링 | `doParry`는 반경 2.4m 충격파 — 보스에게도 0.5피해·0.35초 경직은 들어가지만 **돌진을 끊지 못한다** | "보스 공격을 받아친다"는 판정이 아직 없다 |
| 참 게이지 수입 | 잡몹 처치 +7 · 보스 절단 +10 · 웨이브 격파 +15 | 잡몹을 없애면 참이 마른다 → **대체 수입 설계가 필요** |

### 3.2 개편안

**(a) 결계 1:1 — 잡몹 소환 제거**

- 전 장 `STAGES[].boss.adds = 0`. `stepBoss`의 소환 분기는 삭제하지 않고 `adds > 0`일 때만 도는 현행 구조를 그대로 두어, 훗날 특수 장(예: 12장 2페이즈)에서만 되살릴 수 있게 남긴다.
- 보스전 중에는 묵항아리도 띄우지 않는다(결계 안 소품은 결계 연출만).
- 결과: 화면에 플레이어·보스·공격물·혼령만 남는다.

**(b) 원혼 구슬 · 검기 기둥 — 공격물에 돌진해 역공**

| 단계 | 규칙 |
|---|---|
| 생성 | 보스가 `telegraph`에 들어가는 순간, 결계 테두리 안쪽 `r = 7.2~9.6m`에 보스 기준 90~270° 부채꼴로 N개 생성. 위에 **이번 장 혼령 기호 1개**가 뜬다(장의 `shapes` 풀에서 선택, 보스 절단 순서와 무관) |
| 수명 | 예고 시간 + 0.4초(2.0~2.6초). 살아 있는 동안 초당 0.6m로 보스 쪽으로 흘러간다 |
| 판정 | 공격물 1.6m 안으로 **일섬 돌진**이 지나가면 **역류**. 공격물이 먹 궤적을 그리며 보스에게 날아가 명중 → **보스 경직 1.0초** + 참 **+12** |
| 경직 후 | 기존 파훼 규칙 그대로 — 경직 중 등 뒤를 베면 **2연속 절단**("파훼!") |
| 실패 | 수명이 다하면 제자리에서 결계 광역 폭발(0.5초 예고, 반경 3.5m, 1피해) |
| 허상 | 3개가 뜨는 후반 장에서는 그중 1개만 '진짜'(혼령 빛이 실처럼 보스와 연결), 나머지는 베면 연기로 흩어지고 참 +4 |

- **개수**: 3~4장 1개 → 5~8장 2개 → 9~12장 3개(유효 1~2).
- **의도**: "표적을 베는" 행위가 곧 **회피**이자 **보스 경직 만들기**가 된다. 돌진 무적 프레임(기존 `dash`)을 그대로 쓰므로 새 조작을 배울 필요가 없다.

**(c) 보스 강공 받아치기 — 제자리 탭 패링**

| 항목 | 값 |
|---|---|
| 대상 | 돌진 충돌 **직전 0.30초**, 그리고 신설 기술 **내려치기** 착탄 0.30초 전 |
| 조건 | 보스와 거리 ≤ 3.6m + 제자리 탭(기존 `isTap`: 이동 22px·박스 16px 이내) · 보스 1회 공격당 1회만 판정 |
| 성공 | 무피해 · 히트스톱 **0.10초** · `audio.parry()` · 보스 **경직 1.4초**(기존 `stun` 상태 재사용, `stateT = 0`) · 참 **+15** · 화면 판정 "챙—!" |
| 경직 후 | 파훼 창 — 경직 중 베면 2연속 절단 |
| 실패 | 기존과 동일(피해 2, `iframe` 0.8초). 실패해도 `parryCd`는 0.45초로 묶어 연타 남발 방지 |
| 내려치기(신설) | 7장~ 보스가 예고 0.9초 뒤 반경 4.0m 강타(2피해, 바닥 균열 연출). 돌진만으로는 탭 타이밍이 애매해서 만든 패링 전용 표적 |

**(d) 장별 보스전 구성**

| 장 | 잡몹 | 공격물 | 보스 강공 | 패링 경직 | 장판 |
|---|---|---|---|---|---|
| 1~2 | 0 | – | 돌진 | 1.0초 | – |
| 3~4 | 0 | 1 | 돌진 | 1.2초 | 1 |
| 5~6 | 0 | 2 | 돌진 + 내려치기 | 1.2초 | 2~3 |
| 7~8 | 0 | 2 | 돌진 + 내려치기 | 1.4초 | 3~4 |
| 9~10 | 0 | 3(유효 2) | 돌진 + 내려치기 + 2연 돌진 | 1.4초 | 4 |
| 11~12 | 0 | 3(유효 2) | 위 전부 + 돌진 후 즉시 내려치기 | 1.4초 | 5 |

**(e) 참(斬) 수입 재균형**

잡몹 +7이 사라지므로 보스전 참 수입을 공격물·패링으로 옮긴다.

- 결계 테두리(`three.arena`)의 금빛 실이 유효 공격물과 이어져 "베어야 할 것"을 색이 아니라 **선**으로 알려 준다.

### 4.3 소리 3층

- **칼날**: `audio.slash()` — 획의 길이에 따라 음 높이 +0~2도.
- **먹/살점**: `audio.hit()` — 명중 시. '정확한 획'(perfect)이면 한 겹 더.
- **저역**: `audio.drum()` — 처치·파훼에만. 매 명중에 넣으면 피로하다.
- 종소리는 처치 12킬당 1회로 제한(남발 금지).

### 4.4 먹물·잔상

- 명중 지점에 먹 방울 3~6개(기존 `three.ink.kill` 재사용, 크기 0.6배).
- 일섬 잔상(`afterimages`) 유지 시간 0.16~0.22초 → **0.20~0.28초**로 늘려 궤적이 남게.
- 처치 순간 흰 섬광은 넣지 않는다(수묵 톤 유지). 대신 먹 번짐 반경 ×1.4.

### 4.5 참(斬) 준비 안내

| 상태 | 현행 | v0.24 |
|---|---|---|
| HUD 텍스트 | `참 준비` (`renderCharge`) | **`참 준비 (O 그리기!)`** |

| 첫 도달 | – | 토스트 1회 "참(斬) — 동그라미를 그리세요" |
| 발동 후 | – | 게이지 0 → 재충전 동안 안내 최소화 |

모바일에서 `O`를 그리라는 사실을 모르는 것이 v0.23의 실제 이탈 요인이었다. 상시 표시는 발동 한 번까지, 이후엔 게이지가 찰 때만.

## 5. 자동 발동 보조 스킬(호신부)

### 5.1 설계 원칙

- **손을 놓아도 되지만, 손을 쓰는 게 더 세다.** 자동 스킬 DPS는 총 DPS의 **15~25%** 이내.
- 새 조작 없음 — 이동만으로 작동. 제스처의 대체가 아니라 **완급**이다.
- 참 게이지를 자동으로 채우지 않는다(자동 처치 +3, 일반 처치 +7의 절반 이하).

### 5.2 스킬 2계열

| 계열 | Lv | 효과 | 수치 |
|---|---|---|---|
| **회전 호신부** | 1~3 | 부적 2개가 반경 2.2m를 회전, 접촉한 적에게 0.8피해/0.35초 | Lv2 반경 2.6m, Lv3 부적 4개 |
| **진노의 벼락부적** | 1~5 | 4.5초마다 6m 내 최밀집 지점에 낙뢰(반경 2.2m, 2.2피해, 0.6초 예고) | Lv마다 간격 −0.4초(최소 2.8초), 피해 +0.3 |

### 5.3 진화 2종

| 진화 | 조건 | 효과 |
|---|---|---|
| **만륜(萬輪)** | 회전 호신부 Lv3 + 심안 반경 Lv3 | 회전 반경 +1.2m, 접촉 시 0.3초 감속 |

## 6. 첫 10초 몸통 튜토리얼

### 6.1 현행

`practiceSec = 10` · `practiceSpawns = 6` · 첫 10초 잔몹 상한 2 · 화면에 `SHAPE_HINT` 텍스트("가로로 길게 그어 보세요") · 스테이지 `tip`은 타이틀 카드에 표시. **슬로우모션·유도 획·탭 안내는 없다.**

### 6.2 3단 구성 (총 10초)

| 시각 | 연출 | 텍스트 |
|---|---|---|
| 0.0~0.5초 | 시간 0.45배. 첫 혼령 위로 반투명 유도 획이 그려지고, 그 방향을 따라 손가락 궤적 가이드가 흐른다 | "그어 보세요" |
| 첫 성공 | 히트스톱 0.05초 · `audio.slash` · 시간 0.75배 | "일섬!" |
| 5.0초 | 슬로우 0.35배 0.6초. 앞에서 잡몹 1마리 접근, 영웅 주위에 패링 링 표시 | "제자리 탭" |
| 탭 성공 | "챙-" · 잡몹 넉백. **실패해도 피해 없음**(튜토리얼 중 `iframe` 고정) | – |
| 10.0초 | 안내 종료, 정상 시간·정상 스폰 | – |

- **텍스트는 화면당 6자 이내, 총 3개.** 설명창 없음.
- **조건**: `save.tutorialDone`이 없고 **1장 첫 진입**일 때만. 2장부터는 기존 `practiceSec` 획 연습만.
- **건너뛰기**: 우상단 '건너뛰기' 칩 상시. 누르면 즉시 종료 + `tutorialDone = 1`.
- **다시 보기**: 타이틀 카드에 '수련' 버튼(1장 고정, 점수 미반영).
- **접근성**: `qa.noDelay` 또는 `prefers-reduced-motion`이면 슬로우 없이 안내 문구만.

기존 `practiceShape`/`SHAPE_HINT` 시스템은 그대로 두고 그 위에 얹는다(새 획이 열리는 3·4장에서도 같은 안내가 재사용된다).

## 7. 로비 영구 해금·도감·메타 성장 루프

### 7.1 현행

`save`는 `{ coins, atkLv, hpLv, coinLv, cleared, best, runs, stage, stars, bestScore }` — 영구 성장은 **공격력·체력·코인 3종**(각 maxLv 10, 비용 `upgradeBase = 15`부터)뿐이고, 수집 요소가 없다. 타이틀의 '성장' 버튼이 이 3종 상점이다.

### 7.2 save v3

```js
save = {
  // 기존 유지: coins, atkLv, hpLv, coinLv, cleared, best, runs, stage, stars, bestScore
  version: 3,
  tutorialDone: 1,
  unlocks: { swords: ['heukmuk'], relics: [] },
  codex: { beasts: {}, evolutions: {} },   // id -> 1(해금)
  equipped: { sword: 'heukmuk', relic: null }
}
```

불러오기에서 `version`이 없으면 기존 키를 그대로 살린 채 새 키만 기본값으로 채운다(기존 세이브·별 기록 보존).

### 7.3 무구(검) 5종

| 이름 | 가격(엽전) | 효과 | 해금 |
|---|---|---|---|
| 흑묵도 | 0 | 기본 | 처음부터 |
| 청운도 | 600 | 판 시작 시 참 +20 | 3장 첫 클리어 시 도면 지급 |
| 무명도 | 900 | 칼집 패링 반경 +0.4m | 6장 첫 클리어 |
| 혈묵도 | 1,200 | 처치 시 체력 1 회복(8초 쿨) | 9장 첫 클리어 |
| 빈검(空劍) | 1,500 | 일섬 횟수 +1, 일섬 피해 −10% | 12장 클리어 |

### 7.4 유물 8종 (판 시작 시 1개 장착, 가격 250~700)

예: 시작 참 30 · 혼령 슬롯 +1 · 묵항아리 드롭 2배 · 첫 패링 무료 · 공격물 역류 시 참 +6 추가 · 보스 경직 +0.3초 · 엽전 +10% · 첫 피격 무효 1회.

### 7.5 도감 27칸

| 묶음 | 칸 수 | 해금 조건 |
|---|---|---|
| 귀물 | 8 (imp·brute·stone·elite·charger·thrower·bomber·보스 공통) | 처음 처치 |
| 보스 | 12 (장별) | 해당 장 클리어 |
| 진화 | 7 (기존 5 + 만륜·뇌빙) | 해당 진화 1회 발동 |

- 칸마다 이름·한 줄 설명·대응법 2줄. 완성 시 엽전 +10%.
- 결과 화면에 "새로 해금" 배지 → 다음 판 동기.

### 7.6 경제 균형

12장 147킬 기준 한 판 엽전 ≈ **500**(처치 엽전 + 드롭, 추정). 무구 600~1,500 = **1.5~3판**, 유물 250~700 = **1판 이내**. 첫 클리어 도면 지급으로 12장 올클리어까지 5종 중 4종을 무료로 얻는다 → "돈이 모자라 못 산다"는 느낌 없이 수집이 진행된다.
