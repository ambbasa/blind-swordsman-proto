# 심안(SIMAN) v0.50 ~ v0.52 보스전 전면 개편 문서

## 1. 보스전 HP 대결 체계 (v0.48.5 `840bdd0` 도입 → v0.52 완성)
기존의 "정해진 무늬 배열을 차례로 베어 즉사" 방식에서 **HP 대결 + 빈틈(×1.3) 파훼 + 최종 한붓별(★) 봉인** 체계로 전환 및 완성했습니다.

- **장별 보스 최대 HP**: `[18, 23, 28, 32, 37, 42, 47, 52, 55, 63, 71, 80]` (1장 18 ~ 12장 80)
- **피해 배율 및 빈틈(`openUntil`)**:
  - 일반 피격: `×0.7`
  - 보스 패턴 중 약점 무늬 타격·패링·역공 성공 시 **빈틈 1.8초(빙결 시 +0.4초)** 개방 → **`×1.3` 약점 피해**
  - 금빛 부적 반사 명중 시 빈틈 개방 + 즉시 `3.2` 반격 피해
- **v0.52 보강 및 버그 수정**:
  - **타격감 복구**: `hurtZombie()` 보스 분기에 누락되어 있던 타격음(`audio.hit`), 히트스톱, 먹파편(`three.ink.hit`/`three.paper.hit`), 흰 피격 섬광(`flinchT`), 일반/약점 플로팅 데미지 숫자를 모두 복구.
  - **봉인(`seal`) 시간 초과 고착 버그 수정**: 제한 시간 내 한붓별 봉인 실패 시 `hp = 0`에 갇히던 문제를 수정해 최대 HP의 22%(최소 4)를 회복하고 전투에 정상 복귀하도록 교정.
  - **상단 보스 HP 바 고도화**: 옻칠 먹 프레임 + 흰금 잔상 데미지 트레일(`hpTrail`) + 페이즈 눈금 + 빈틈 개방 시 하단 금빛 **`빈틈 열림 · 피해 ×1.3`** 카운트다운 띠 추가. 혼선을 주던 머리 위 구식 무늬 배열 칩 제거.

## 2. 보스 3D 모델링·보행 모션 (v0.50 ~ v0.51)
- **조선 수묵 다크판타지 통일** (`v2/js/inkmodels3d.js`):
  - 주인공(`먹색 도포·환도`)과 일관된 저채도 먹흑/쪽먹/송연먹/심연 묵자 팔레트, 한지빛 안깃(동정), 넓은 조선 흑갓·전립(고청동 상모·한지 부적), 고목 귀면탈, 사선 대염주, 발목까지 흐르는 주름 철릭·도포 자락, 은철 언월도(偃月刀)로 재조형.
- **보행 속도·애니메이션 교정** (`v2/js/modules/balance.js`, `v2/js/inkmonsters3d.js`, `v2/js/game.js`):
  - `bossSpeed: 1.0 → 1.85 m/s`, `walkDur: 1.80s → 0.94s`, `'boss:walk'` 상태 누락 버그 수정.
  - `slamTele` 순간이동 제거 → 포물선 공중 도약(`z.leapY`) + 내려찍기 착지, 돌진·횡참·예고 중 목표 방향 시선 고정.

## 3. 커스텀 수묵 보스 스킬 에셋 & 원글랜스 타이밍 가독성 (v0.52)
- **커스텀 RGBA WebP 에셋 4종** (`v2/assets/boss-fx/`):
  - `boss-mandala.webp`: 내려찍기·장판·영창·기모으기 회전 수묵 진법
  - `boss-impact.webp`: 내려찍기·장판 폭발 지면 균열 크레이터
  - `boss-talisman.webp`: 비행 살부적 투사체 (금빛 패링 부적은 근접 시 `탭!` 표시)
  - `boss-wave.webp`: 언월 횡참 및 2페이즈 돌진 마무리 초승달 검기 파동
- **원글랜스 통합 스킬 배너 & 수렴 타이밍 시스템** (`v2/js/bossFx.js`):
  - 상단 보스 HP 바 바로 아래에 `[회피]` / `[받아치기]` / `[파훼]` / `[봉인]` 대응 배지 + 스킬명 + 행동 문구 + 스위트스팟 타이밍 바를 통합 표시.
  - 모든 바닥 예고에 고정 위험 경계 + `f → 1.0` 수렴 백금 타이밍 링 + 발동 0.22초 전 백색 섬광·청각 틱(`audio.bell`)을 동기화.
  - 기모으기(`kiai`) 패링 창 개방 순간 주인공 주위에도 금빛 링 + **`破 · 지금 탭!`** 즉시 표시.
- **신규 스킬 & 다단 패턴**:
  - 신규 스킬 **`언월 횡참(sweep)`**: 120° 부채꼴 광역 베기 + 전진 초승달 검기 파동 (`+ 2페이즈/4장+` 양옆 살부적 2발, 1발 패링 가능).
  - `charge` 끝자락 검기 파동 추격, `slam` 착지 후 양옆 여진 장판 2개 추가(2페이즈/4장+).
