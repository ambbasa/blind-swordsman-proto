# 장별 전장 · 3D 지형지물 제작 목록

[공식 레퍼런스의 전투 화면](https://store.steampowered.com/app/3470500/Ember_and_Blade/)에서 참고한 것은 중앙 캐릭터와 공격 이펙트의 대비, 비스듬히 내려다보는 시야, 가장자리에서 전장을 설명하는 무너진 구조물이다. [라인게임즈 제공 전투 스크린샷](https://www.newsis.com/view/NISX20250411_0003135725)에서도 배경보다 번개와 적 실루엣이 먼저 읽힌다. 원작의 맵이나 에셋을 옮기지 않는다. 심안의 장터·사찰·나루·봉인 테마와 획을 긋는 중앙 공간을 기준으로 배치한다.

## 현재 배치된 공용 리소스

- 소나무, 바위 군집, 등롱, 사당은 현재 기존 GLB를 사용한다. 이 4종도 [새 원화 및 정적 GLB 생성 스크립트](../design/scenery-concepts/README.md)로 교체 후보를 만들 수 있다. 성벽, 기와집, 좌판, 대숲, 정자, 돌무더기, 문, 고사목, 석등, 뼈 아치 등은 기존 절차형 메시를 공유한다. 전경의 낮은 목재·깨진 판석·갈대와 자갈 군락도 같은 메시를 재사용한다. 전용 모델이 없는 장도 빈자리나 다운로드 오류 없이 보인다.
- 길·돌바닥·강바닥·뜰의 문양과 접지 그림자는 지면에 직접 그린다. 이들은 별도 GLB 제작 대상이 아니다.

## 모델 교체

1. 정적인 glTF 2.0 바이너리를 [공용 모델 디렉터리](../v2/assets/models/props/)에 넣는다. Y축이 위, 정면은 로컬 +Z 기준이다. 바닥과 수평 중심은 로더가 맞추며 전체 장면의 높이를 표의 값에 맞춰 균일하게 스케일한다.
2. [배치 명세](../v2/js/modules/stageScenery.js)의 해당 키에서 `model: null`을 파일명으로 바꾼다. 예: `marketAwning` → `model: 'marketAwning.glb'`. 장 배치나 게임 로직은 건드리지 않는다. 메시가 여러 개인 모델도 한 벌로 교체된다.
3. 위치·회전·충돌은 슬롯이 소유한다. 대체 모델은 임시 기물과 비슷한 바닥 면적을 유지한다. 긴 처마·아치는 캐릭터 높이의 이동로를 가리지 않는지 확인한다. 텍스처에는 광택이나 조명 효과를 굽지 않고 밝은 면·그늘·강한 실루엣 위주로 제작한다.
4. 해당 장에 진입해 기본 화면과 `?props=proc` 화면을 비교한다. 파일 누락·로드 실패 시에는 기존 기물이 남는다. 교체 후 중앙의 검객, 적의 종·공격 표시, HUD가 가려지지 않는지 실제 카메라에서 확인한다.
