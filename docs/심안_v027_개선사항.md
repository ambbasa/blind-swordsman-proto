# 『심안』 v0.27 개선 사항

`reports/2026-11-17-심안-최신버전-실플레이-문제점.md`(v0.26 실플레이 QA)의 P1·P2 항목과
창현님 요청 두 가지(화면 크기별 동일한 시야, 혼령과 이어지는 영혼 흐름을 얇고 연하게)를 반영했다.

## 1. 화면 크기별 동일한 시야 (요청 ①)

- 카메라를 **짧은 축 고정 스케일**로 바꿨다. 화면의 짧은 축이 언제나 같은 세계 폭(≈16.6m)을 담는다.
  - FOV를 화면 비율에 맞춰 다시 계산한다(`viewFov`): 390×844 → 61.4°, 844×390 가로 → 30.7°, 1440×900 → 45.2°.
  - 그래서 캐릭터·시야 원·보스의 픽셀 크기가 화면마다 같고, 넓은 축만 더 많이 보인다.
    (예전에는 세로 FOV가 62°로 고정이라 가로 화면에서 세상이 2.2배 작게 보였다.)
  - 큰 화면(짧은 축 390px 초과)은 √ 비율로만 완만히 넓혀 데스크톱에서 과도하게 확대되지 않게 했다.
- `screenRingPx()`를 짧은 축 기준으로 바꿔 시야 원이 화면의 70%(심안 반경 Lv3 90%)를 언제나 차지한다.
- 보스 결계에 들어가면 FOV를 1.10배 넓히고, 시선을 보스 쪽으로 최대 2.6m 옮겨(`updateCam`의 `S.focus`)
  보스의 발과 예고 동작이 화면 아래로 잘리지 않게 했다. 390×844에서 보스 40개 위치(거리 4~12m × 8방향)를
  투영해 확인: 발끝 최대 y=624(화면 844), 머리 최소 y=216 — 잘림 0건.
- HUD를 3줄로 재배치했다(1줄: 장·타이머·엽전·콤보 / 2줄: 체력·참 게이지·참 라벨·경험치·Lv / 3줄: 일섬).
  - 390px에서 2줄로 갈라지던 `참 / 20`은 `참 20`·`참 준비 (O)` 한 줄로 고정(`white-space: nowrap`).
  - 체력 핍은 12개까지만 그리고 초과분은 `+N`으로 적는다(`flex-wrap: nowrap`).
  - 장 이름은 40% 폭에서 말줄임, 1줄은 말줄임/고정폭으로 넘침 제거 → 390px 기준 행 폭 469 → 370px.
  - 데스크톱에서는 HUD 줄 폭을 780px로 묶어 화면 양끝으로 흩어지지 않게 했다.
  - 가로·낮은 화면(높이 560px 이하)은 HUD 높이 85 → 62px로 줄여 시야를 확보했다.

## 2. 영혼 흐름을 얇고 연하게 (요청 ②)

- `drawSoulStreams()`의 리본 반경 10→5px, 알파 0.16→0.11, 흐르는 입자 5→4개·반경 7→3.4px.
- 혼령 몸통과 구분되도록 **흰 심지(226,255,244)를 없애고** 비취빛(110,214,176 / 88,190,160)만 남겼다.
- `CFG.spiritStreamAlpha` 0.7 → 0.55. 혼령 구슬 자체의 밝기는 그대로 두어 "혼령이 더 밝고, 흐름은 연한 먹기운"이 됐다.

## 4. P2 수정

- **O 40° 열림 허용**: `scoreCircle` closure 문턱 0.32→0.46(완만). 8~44° 틈새까지 '동그라미'로 인식.
- **얕은 V**: 높이 문턱 28→13px. 폭 90·깊이 20px V도 `vee`로 인식(이전엔 가로선).
- **좁은 번개**: `scoreBolt` 단순화 여유를 획 폭에 맞추고(폭 20px 지그재그도 인식), 지그재그가 확인되면 축 흡수보다 우선.
  손 떨림(±5px 물결)은 직선으로 유지되도록 폭 비율·꺾임 급격도 조건 추가.
- **실패 토스트 줄바꿈**: `#toast`에 `word-break: keep-all` + `width: max-content`(폭 195→387px, 5줄→3줄).
- **`(최대)` 하드코딩**: 다음 레벨이 실제 최대일 때만 표시.
- **음소거·일시정지·나가기**: HUD 우하단 버튼(♪/❚❚)과 일시정지 카드(계속·소리·나가기). 설정은 저장된다. ESC로도 토글.
- **데스크톱·가로 HUD**: 위 1항.
- **상점 비활성 대비**: `.shop-item:disabled` 불투명도·테두리 상향.
- **경제**: `coinPerKill` 3→2, `upgradeBase` 15→20 (3종 만렙까지 6판 → 12판 내외).
- **정확한 획**: 인식기가 `q`(직선은 축 이탈 정도, 나머지는 모양 점수)를 계산하고 `applyPath`가 그 값을 쓴다.
  깨끗한 가로획 q=1.00 / ±8px 흔들린 가로획 q=0.51 → 이제 "늘 ×1.5"가 아니라 실제로 잘 그어야 발동.
- **머리 주석**: v0.23 → v0.27.
