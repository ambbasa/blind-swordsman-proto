# 심안 v0.79.2 — 기본 3D 복귀 · 5종 관절 자세·공격 모션 개선

## 1. 기본 렌더를 다시 3D GLB 로
- `v2/js/hd2dSprite.js` 기본값을 `enabled = false` 로 바꿨다.
  HD-2D 빌보드는 `?render=hd2d` 또는 `?hd2d=1` 로만 켠다(비교·복귀용).
- 기본 접속(`/v2/`)에서 `hero.glb` + `minion/heavy/stone/boss.glb` 4종이 그대로 렌더링된다.

## 2. 왜 자세 레이어가 필요했나
5종 GLB 의 내장 클립은 `hips`·`foot` 채널이 사실상 2키(정지)라 걷기가 미끄러지고,
대기 자세가 꼿꼿한 A 포즈에 가까웠다. 그래서 `mixer.update(dt)` **뒤에** 본 쿼터니언을 다시 쓰는
절차 자세 레이어 `v2/js/glbpose.js` 를 새로 넣었다.

- 축 규칙(실측 캘리브레이션): 정면 `+Z`, `rx>0` = 위로 뻗은 뼈는 앞숙임·아래로 뻗은 뼈는 뒤젖힘,
  `ry>0` = 왼쪽 회전, 팔 벌리기 = 왼팔 `+rz` / 오른팔 `-rz`.
- 로컬 변환: `bone.quaternion = (P0⁻¹ · R · P0) · q0` (P0 = 부모 rest 월드 쿼터니언)
- **접지 자동 보정**: 두 발의 발바닥 점을 해석적 FK 로 재서 가장 낮은 발이 지면(y=0)에 닿도록
  골반 높이를 매 프레임 보정한다. 무릎을 굽혀도 발이 뜨지 않고, 접지점은 rest 자세에서
  발목 바로 아래 지면 점을 발뼈 로컬 좌표로 옮겨 두어 발이 돌아가도 함께 움직인다.
- 상태 전이는 이전 자세에서 0.16초(공격·피격 0.07초) 블렌딩, 걷기 위상은 이동 속도/보폭으로 적분.

## 3. 캐릭터별 개선점
| 종 | 대기 | 걷기 | 공격 |
|---|---|---|---|
| 주인공(hero) | 오른발 뒤·무릎 굽힌 낮은 중단세, 상체 13° 전경, 검을 앞으로 겨눔, 호흡 | 상체 전경 + 검을 뒤로 빼고 팔·다리 교차 보행, 어깨 반동 | 어깨 뒤로 젖힘(예비) → 몸통 회전 대각 베기 → 팔로우 스루 → 복귀 |
| 원귀(minion) | 등 굽힘 + 고개 떨어뜨림, 두 팔 앞으로 뻗은 좀비 자세 | 좌우로 비틀거리는 보행(어깨 처짐·몸통 흔들림) | 두 팔 번쩍 → 상체 앞쏠림 덮치기 → 웅크림 → 일어나며 팔 재차 뻗기 |
| 거구(heavy) | 넓은 다리·어깨 으쓱, 묵직한 호흡 | 보폭 큰 걸음 + 어깨 흔들림 | 양팔 옆으로 크게 들기 → 내려치기 → 여파 → 복귀 |
| 석인(stone) | 각 잡힌 직립, 팔 벌림 | 무거운 짧은 보폭 | 두 팔 위로 → 내리찍기 → 복귀 |
| 보스(boss) | 위엄 있는 와이드 스탠스 | 보스 특유의 느린 보폭 | 양손 높이 들기 → 내려찍기 → 낮게 깔리는 여파 → 복귀, `wind` 는 캐스트 자세 |

- 극단 각도(상체 합산 피치 70°+)는 단일 메쉬(Hunyuan3D) 특성상 목·허리 메쉬가 뭉개져
  합산 40~45° 로 제한했다. 팔 스윙은 관절별로 분산해 동작은 크게 보이게 유지.
- 몬스터 공격 트리거 점검: `glbboss.js` 의 `attack`/`cast`/`death` 클립 재생과
  `inkmonsters3d.js` 의 `planFor()` 상태 매핑이 실제로 `attack` 클립을 재생함을 인게임에서 확인
  (`glbCur: "attack"`).
