## 1. 무엇을 바꿨나

v0.36 은 소품을 캔버스 코드로 그린 '한지 팝업북'이었다. v0.37 은 **실제 그림 PNG** 로 갈아 끼우고,
밤 무대의 조도·안개·배경을 그 그림에 맞춰 다시 잡았다.

| 항목 | v0.36 | v0.37 |
|---|---|---|
| 소품 | `inkpaper.js` 절차 캔버스 5종 | `images` CLI 로 그린 수묵화 PNG 5종 (`v2/assets/diorama/`) + 절차 캔버스 폴백 |
| 소품 평면 | 교차 평면 2장(집이 X자로 겹쳐 보임) | 집·소나무·석등·바위는 **카메라를 바라보는 한 장**, 대나무만 교차 2장 |
| 바닥 | 절차 판석 256px | images 로 구운 **사각 돌판 512px + 그 휘도에서 뽑은 노멀·러프니스** (1.2m 판석 4×4, 4.8m 주기) |
| 배경 | 없음 | **접이식 비단 산수 병풍** — 화면 위쪽 170° 원호(반경 21m, 높이 11m, 10판, 드로우콜 1) |
| 등불 | 중앙 점광원 0xffa955/46 | 0xffb45c/34(거리 20m, decay 1.7) — 호박빛 못을 좁고 진하게 |
| 2D 먹안개 | 전면 균일 | **화면 맨 위 34%만 안개를 26~52% 덜어** 병풍·원경 실루엣이 읽히게 |
| 소품 밝기 | — | 기와집·석등은 창호지 창에 emissiveMap(0.42) |

## 3. 코드

- 신규 `v2/js/inkdiorama.js` — 모듈 로드와 동시에 9장을 `Image.decode()` 로 비동기 로드, 텍스처 캐시.
  하나라도 실패하면 그 소품만 절차 캔버스로 폴백한다(게임은 그대로 돈다).
- `v2/js/inkchunks.js` — 소품 재질/평면, 바닥 텍스처(장별 색조, 최근 4장 캐시), 병풍 원호, 청크당 소품 수 통계.
- `v2/js/game.js` — 부팅 시 프리로드, 2D 먹안개 상단 감쇄, `GPv2.diorama()` QA 훅.
- `v2/js/inkprops3d.js` — 바닥 등불빛 쿼드 opacity 0.62→0.40, 색 0xff7a2b 계열로 진하게(흰 원으로 타던 문제).

### QA 조정 노브(URL)
`?floorMul=0.7`(바닥 밝기), `?screenR=21`, `?screenH=11`(병풍 반경·높이) — 스크린샷 비교용.
