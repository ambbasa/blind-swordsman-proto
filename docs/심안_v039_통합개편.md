# 심안 v0.39 — Papertrails 통합 개편 1~3단계 (팔레트 · 월드 안개 · 종이 재질)

기준 커밋 `2224192`(v0.38) · 대상 `v2/` · 근거 `/workspace/reports/2026-11-19-심안-papertrails-비교분석.md`

## 1. 무엇을 바꿨나

『심안』은 v0.36~v0.38에서 비단 병풍 디오라마·종이 소품·파츠 리그까지 왔지만, **색·안개·재질이 각자 다른 규칙**으로
놀고 있었다(비취 하나만 봐도 CSS `#2ee6a6` / 소나 `#5eead4` / 지면 `#5BE8C4`). v0.39는 그 셋을 한 세트로 묶는다.

| 층 | v0.38 | v0.39 |
|---|---|---|
| 색 | CSS 변수 · 2D 캔버스 · 3D 재질이 각자 hex 를 들고 있음 | `js/palette.js` 단일 팔레트 토큰 → CSS 변수 주입 + `inverseTone` 역톤매핑 |
| 안개 | 2D `#sightFog` 캔버스(화면 타원) + 지면 전용 3D 안개(0.42) + 혼령 창 뚫기 | 월드 거리 fade-to-dark 한 규칙 — 지면·소품·기물·병풍·캐릭터·입자, 후처리에 마지막 한 겹 |
| 재질 | MeshStandard + PNG 컷아웃. 캐릭터 파츠는 조명을 안 받는 MeshBasic | 랩 라이팅 + 얇은 종이 역광 + 시트별 톤을 모든 소품·빌보드가 공유 |
| 그림자 | 60m 고정 ortho 1024 | 카메라 가시 바닥에 매 프레임 피팅 + 텍셀 스냅 + PCF 페넘브라(2048/1024) |
| 소리 | 이벤트마다 오실레이터를 즉석 생성, 0.25초 6개 상한 | 공용 오디오 버스 — 보이스 슬롯·토큰버킷·밀도 덕킹·방 초기반사·소프트니 리미터 |

## 2. 1단계 — 톤 기준선

### `v2/js/palette.js` (신규)
- `PALETTE`: 먹(`ink`·`ink2`·`inkWash`) · 한지(`paper`·`paperDim`·`hanji`·`cutEdge`) · 비취(`jade` 방출 / `jadeInk` 안료) ·
  진홍(`vermilion`·`vermilionHot`·`rust`) · 금(`gold`·`goldHot`) · 보랏빛(`violet`·`violetPale`) · 안개·입자·등불 · 조명 리그 기본값.
- `installCssVars()` — 같은 값을 `--sm-*` 사용자 속성으로 `documentElement` 에 주입. `style.css` 의 `:root` 가 같은 값의
  정적 기본값을 들고 있어 JS 가 늦어도 화면은 그대로다. 예전 이름(`--ink`·`--paper`·`--gold`·`--jade`·`--siman-*`)은
  전부 토큰을 가리키는 **별칭**으로만 남겼다(규칙을 하나하나 고치지 않고도 단일 소스가 된다).
- `inverseTone(hex)` — 후처리(`inkwash` 수묵 wash → `cinematic` 노출 1.32 · ACES → sRGB)를 JS 로 그대로 옮겨 두고
  40회 수렴으로 "화면에서 이 색으로 보이는" 장면 안 색을 구한다. `tonedColor()` 는 캐시판.

### CSS 정리 (`style.css`, `ux-upgrade.css`)
- `.card` 3중 정의 → 1개(최종 톤 + 스크롤에 필요했던 `max-height/box-sizing/text-align`)로 병합.
- `#hud` 2중 정의 병합. `#sightFog` 규칙 삭제(캔버스 은퇴). 사문화된 `--siman-*` 정의는 별칭으로 흡수.
- `ux-upgrade.css` 는 토큰을 다시 정의하지 않는다(규칙만).

### `v2/js/audiobus.js` (신규) + `audio.js` 배선
```
소스 → input ┬ dry ─────────────────────────────┐
             └ 컨볼버(8~42ms 7탭 + 0.6s 꼬리) → wet ┴→ 컴프레서 → 소프트니 리미터(무릎 0.6) → 마스터 → 스피커
```
- 한 소리 = 보이스 슬롯 하나(`voice()`). 상한 8, 넘치면 **지금 가장 조용한 소리**를 20ms 로 걷어낸다.
- 토큰버킷 초 30 / 버스트 9 — 과밀 프레임의 겹침을 정리(소리가 사방으로 튀지 않게).
- 밀도 덕킹 — 이미 울리는 소리가 많을수록 새 소리를 최대 42% 눌러 잡음 밭이 되지 않게.
- 합성 자체(방울 클러스터·베기·타격·대금·북)는 **그대로** 두고 나가는 길만 바꿨다.

## 3. 2단계 — 안개 통합 (월드 스페이스 fade-to-dark)

### `v2/js/cardstock.js` (신규) — 재질 한 겹
지면·소품·기물·병풍·캐릭터 파츠·혼령 빌보드가 모두 이 패치를 지난다. 재질 종류별 프로필:

| 프로필 | 잠김 | 실루엣 유지 높이 | 톤 | 역광 |
|---|---|---|---|---|
| `ground` | 1.00 | 2.6m | ±4.5% | — |
| `prop` / `paper` | 0.92 | 3.4 / 4.0m | ±6.0 / 7.5% | 0.14 / 0.26 |
| `backdrop` (원경 병풍·하늘) | 0.50 | 14m | ±3.0% | 0.14 |
| `figure`(원귀·보스 파츠) | **0**(면제) | — | ±3.5% | 0.12 |
| `spirit`(혼령) | **0**(면제) | — | ±2.0% | 0.09 |
| `item`(엽전·혼백) | 0.35 | 1.3m | ±3.0% | 0.10 |

- 거리는 **화면 타원**을 닮도록 잰다: 영웅에서의 xz 오프셋을 카메라 앞뒤 성분만 계수(0.70)로 줄여 길이를 낸다.
  원근 카메라에서 월드 원은 화면 타원보다 위로 길게 투영되므로, 이 계수가 없으면 "예전 2D 안개의 둥근 못"이
  위아래로 늘어난 타원이 된다.
- 링 반경은 `ringR()`(화면 짧은 축 70%에 맞춘 월드 반지름)에서 `0.80R ~ 1.08R` 로 잡고, 파동(`S.fogPulse`)에
  안쪽이 ±7% 숨쉰다. 예전 `CFG.fogInner 0.86 / fogOuter 1.16` 감성의 이관이다.
- 안개색 = 스테이지 `atmo.fogCol`(예전 2D 안개의 `fogRgb()` 그대로). 높은 물체는 안개를 덜 받아
  병풍·지붕·등불 기둥이 어둠 위로 떠 보인다(예전 상단 안개 걷기의 몫).
- **혼령 창(`punchSpiritLights`)이 필요 없어졌다** — 혼령·원귀는 면제 프로필이라 어둠이 표적을 삼키지 않는다.

### `v2/js/inkwash.js` — 후처리 한 겹
- 깊이 역투영(`uInvProj`·`uCamWorld`)으로 픽셀의 월드 좌표를 얻어 **같은 거리 규칙**을 한 번 더 적용하고,
  하늘·구멍(깊이 1.0)은 가장 짙게 잠근다(재질이 놓친 픽셀 안전망).
- `wfKeep()` — 밝기(휘도)만 보고 남긴다. 색이 진하다고 남기면 12장 혈석 같은 붉은 소품이 안개를 통과해 버린다.
  이 규칙 덕에 등불·검기·혼령은 어둠 속에서도 그대로 읽힌다.
- 매 프레임 uniform 만 갱신 — 프레임 할당 0.

### `#sightFog` 캔버스 은퇴
- `index.html`·`style.css` 에서 제거, `drawRingFog`/`punchSpiritLights`/`spiritLightR`/`sizeOverlayCanvas` 삭제.
- `drawSightFog()` 는 남은 세 가지 일만 한다: (a) CSS 레이어가 읽는 `--hero-x/--hero-y`, (b) 심안 파동의 대기 레이어 구멍
  (`punchAtmoRing`), (c) 착지 소나의 3D 지면 uniform.

## 4. 3단계 — 재질 통합 + 그림자 피팅

### 종이 물성 (같은 `cardstock.js`)
1. **랩 라이팅** — three r170 조명 청크의 `dotNL` 계산을, 재질이 `CARD_WRAP` 을 정의했을 때만 **확산항에** 랩(0.34)을
   더하도록 바꾼다. 스톡 문자열이 다르면 경고만 남기고 스톡 그대로(안전 폴백).
   *주의*: `dotNL` 자체를 바꾸면 스페큘러까지 넓어져 등불 아래가 하얗게 타 버린다(1차 시도에서 실제로 그랬다) —
   그래서 확산항에만 더하는 방식으로 확정.
2. **얇은 종이 역광** — 표면이 달빛 반대를 향할수록 따뜻하게 비친다(`uCardTrans`, `uCardTint #ffb070`).
   그림 빌보드(노멀 없음)는 **위쪽 은은한 역광 + 아래쪽 살짝 어두움**으로 제한했다(과하지 않게).
3. **시트별 톤** — 오브젝트 원점 해시로 알베도를 ±2~7.5% 흔든다(같은 집·나무가 다 같은 색이 되지 않게).

### 그림자
- `renderer.shadowMap.type = PCFShadowMap`(반경 사용) + `shadow.radius` 를 프러스텀 반경에 반비례해 1.4~3.4 로.
- `fitShadowFrustum()` — 매 프레임 카메라가 보는 바닥 반경을 재어 0.5m 단위로 ortho 프러스텀을 맞추고,
  그림자 텍셀 격자에 중심을 스냅한다(스냅 없으면 카메라가 움직일 때 그림자 가장자리가 흔들린다).
  영웅 쪽으로 35% 당겨 플레이어 발밑 그림자를 더 선명하게.
- 맵 크기는 품질 레더에 연결: `fx=high` + 단계 0 → 2048, 그 아래 → 1024(바꿀 때 기존 맵 dispose).

### 품질 레더(`applyQuality`)
- 단계가 내려가면 그림자 맵 1024 → 가장 낮은 두 단계에서는 후처리 안개 한 겹을 생략(재질 안개는 유지).
- 재질은 **무늬(defines)로만** 갈리므로 런 중 재링크 없음. 재질 캐싱·`customProgramCacheKey` 합성 유지.
