# 심안 v0.30 개선 사항

v0.29 개선안 §16의 **v0.30 「난이도와 첫 경험」** 묶음(4.3 · 7.2 · 7.3 · 8.1 · 8.2 · 11)을 구현한 기록이다.
수치와 수용 기준은 `design/improvement-plan-v029.md`를 그대로 따랐고, §17의 추천안(수련 별 상한 2개 유지)을 채택했다.

## 1. 난이도 모드 (§7.2)

| 모드 | 예고 | 받는 피해 | 원귀 속도 | 보스 무늬 | 별 | 엽전 |
|---|---|---|---|---|---|---|
| 수련 | ×1.5 | ×0.5 (최소 1) | ×0.85 | −2 | 최대 2 | ×0.7 |
| 정석 (기본) | ×1 | ×1 | ×1 | ±0 | 3 | ×1 |
| 고수 (12장 클리어 후) | ×0.85 | ×1.5 | ×1.1 | +2 | 3 + 금별 | ×1.4 |

- 타이틀 카드에 모드 버튼 3개. 12장 미클리어면 고수는 `12장 클리어`로 잠기고 눌러도 바뀌지 않는다.
- 모드는 `save.mode`에 남고, 장을 옮겨도 유지된다. 판 시작마다 `S.mode`·`S.teleMul`·`S.bossShapeAdj`로 적용된다.
- 적용 지점: `bossTiming().teleT`, `startBossPattern`(기모으기·내려찍기·탄막·영창), `modeDmg()`(직접 타격·돌진 접촉·기합·영창·장판·자폭 전부), `zsp`(원귀 이동), `spawnBoss`의 무늬 수, `grantKill`의 엽전, `starsFor`의 별 상한.
- 고수에서 이긴 판은 결과 화면의 별 3개가 금빛이 되고 `금별` 표시가 붙는다.
- 같은 장에서 정석 3연패면 결과 화면에 **`수련 모드로 한 판`** 버튼이 한 번 뜬다(강요하지 않음, `save.trainOffered`로 같은 연패 수에서는 다시 권하지 않음).

## 2. 동적 보정 (§7.3)

| 연패 | 다음 판 |
|---|---|
| 2패 | 판 시작 참 +30 |
| 3패 | 예고 +10% |
| 4패 | 수련 모드 권유(결과 화면 문구) |

- `save.streak = { stage, n }`은 같은 장에서만 이어진다. 이기면 0.
- **고수 모드에는 적용하지 않는다**(모드 자체가 도전).
- 결과 화면 아래에 `도움이 적용됐다 — 판 시작 참 +30 · 예고 +10%`처럼 **적용된 도움을 그대로 적는다**(투명성).

## 3. 첫 10초 몸통 튜토리얼 (§8.1)

| 시각 | 연출 | 문구 |
|---|---|---|
| 0.0~ | 시간 0.45배. 가장 가까운 혼령 위에 반투명 유도 획, 주인공→혼령 점선 길잡이 | `그어 보세요` |
| 첫 성공 | 히트스톱 0.05초 · 칼소리 · 0.8초 시간 0.75배 | `일섬!` |
| 5.0초 | 0.35배 0.6초, 앞에서 잡몹 1마리 접근, 주인공 둘레 패링 링 | `제자리 탭` |
| 탭 성공 | `챙-` · 넉백. 튜토리얼 동안 `S.iframe ≥ 0.25` 고정 → **실패해도 피해 없음** | — |
| 10.0초 | 안내 종료, 정상 시간·정상 스폰, `save.tutorialDone = 1` | — |

- 문구는 화면당 6자 이내, 총 3개. 설명창 없음.
- 조건: `save.tutorialDone`이 없고 **1장 첫 진입**. 2장부터는 기존 획 연습만.
- 우상단 **`건너뛰기` 칩 상시**. 누르면 즉시 종료 + `tutorialDone = 1`.
- 타이틀 카드 **`수련` 버튼** = 1장 튜토리얼 다시 보기(`startRun({stage:1, replay:true})`). 이 판은 별·점수·최고 기록에 반영되지 않는다.
- `prefers-reduced-motion`이면 느린 화면 없이 안내 문구만.

## 4. '처음 보는 순간' 규칙 (§8.2)

기록은 **저장 단위**(`save.moments`). 한 번 본 것은 다시 늦추지 않는다.

| 처음 보는 것 | 연출 | 기록 키 |
|---|---|---|
| 새 무늬(2·3·4장) | 그 무늬 첫 혼령 위에 0.8초 유도 획 | `shape:vline` `shape:vee` `shape:bolt` … |
| 참 게이지 100 | 화면 가운데 `O` 유도 획 2.2초 + 기존 `참 준비` 안내 | `charge` |
| 보스 패턴 | 예고 ×1.6 · 느린 화면 0.5배 0.6초 · 대응 아이콘 1.6초 | `pat:volley` 등 패턴 9종 |
| 기물 `△ ◡ @` | 보스 등장 직후 3초 기물 연습(시간 0.4배) + 가장 가까운 기물 유도 획 | `totem` |
| 칼 튕김 | 빈틈 고리를 가리키는 화살표 3초 + 한 줄 안내 | `bounce` |

- 같은 장을 다시 해도 이미 본 순간은 다시 늦추지 않는다. QA는 `qa.noFirstMoments`로 기록을 건드리지 않는다.

## 5. 접근성 (§11)

- **색약 팔레트**: 붉은→주황, 비취→청록(`CUE_RGB_CB`). 예고마다 **모양 아이콘**을 함께 그린다 — 피하라 = 바깥 화살표, 받아쳐라 = 칼집, 그려라 = 붓. 붉은 장판에는 바깥으로 뻗은 막대를 8개 그려 색 없이도 읽힌다.
- **화면 흔들림 줄이기**: 진동 폭 ×0.3, 느린 화면은 0.6배까지만.
- 두 설정은 `save.a11y`에 저장하고, 타이틀 `설정`과 일시정지 카드 양쪽에서 같은 값으로 토글된다.

## 6. 보스전 시간 예산 (§4.3)

- 공식은 문서 그대로: `A = time − bossAt`, `C = walk + P + 경직`, `N = ceil(무늬/2)`, `Need = N·C + 봉인 2초`, `Slack = A / Need`.
- **P는 추정 대신 실측**했다(`GPv2.cycleProbe`, 상태기계를 1/30초로 돌려 패턴이 끝날 때까지 잰 값):
  걷기 **2.6초** · 경직 **1.2초** · 기모으기 2.3 · 내려찍기 1.03 · 탄막 0.83 · 영창 4.53 · 분신 8.03 · 은신 5.03 · 결계 수축 2.6(걷기로 끝남).
- 조정: 후반 보스 등장을 앞당겼다 — 8장 172→**162**, 9장 176→**166**, 10장 180→**170**, 11장 188→**176**, 12장 196→**186**.
- 결과(정석 Slack): 8장 1.38→**1.66**, 9장 1.37→**1.65**, 10장 1.40→**1.68**, 11장 1.18→**1.45**, 12장 1.24→**1.47**. 전 장 1.4 이상.
- 고수는 무늬 +2라 3·7·11·12장이 1.17~1.30으로 의도적으로 빠듯하다(도전 모드). 실플레이에서 시간 초과 패배가 10%를 넘으면 다음 수는 고수 무늬 +1 또는 보스 등장 추가 단축.
- 계측: `boss_seen`(등장 시각·남은 시간·무늬 수), `stage_end`에 `timeUp`(시간 초과 패배)·`bossFight`(보스전 길이)·`mode`·`streak`·`help`를 남긴다.

## 7. QA 플래그

- `qa.skipWarm`: 소프트웨어 GL(헤드리스)에서 셰이더 예열이 분 단위로 걸릴 때만 건너뛴다. 실기기·일반 브라우저 경로는 그대로 예열한다.
- `qa.noFirstMoments`: '처음 보는 순간' 기록을 소모하지 않는다(자동 시험용).
