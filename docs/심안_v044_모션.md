# 심안 v0.44 — 60fps 고퀄리티 모션 업그레이드

v0.43(동작당 3~6프레임)에서 눈에 띄던 **스텝 전환의 끊김**을 없애고, 캐릭터·원귀·장정·돌덩이·보스가
물 흐르듯 움직이게 만든 버전. 화풍(얇은 먹 윤곽선·한지 수묵)은 그대로 두고 **자산(그림 수)과 재생 방식**만 끌어올렸다.

## 1. 자산 — 동작당 12프레임

| 캐릭터 | 동작 | v0.43 | v0.44 |
|---|---|---|---|
| 주인공 | idle / walk / slash / hit | 3 / 6 / 5 / 3 | **12 / 12 / 12 / 12** |
| 원귀(좀비) | idle / walk / attack / hit | 3 / 6 / 4 / 3 | **12 / 12 / 12 / 12** |
| 장정 | idle / walk / attack / hit | 3 / 6 / 4 / 3 | **12 / 12 / 12 / 12** |
| 돌덩이 | idle / walk / attack / hit | 3 / 6 / 4 / 3 | **12 / 12 / 12 / 12** |
| 보스 | idle / walk / windup / strike / hit | 3 / 6 / 5 / 4 / 3 | **12 / 12 / 12 / 12 / 12** |

- 생성: `scripts/v044_gen.py` — 기존 스트립을 `--edit` 기준으로 넘겨 디자인을 유지한 채
  **2행×6칸(위 행 1~6, 아래 행 7~12) 12단계 연속 동작**을 다시 그린다(`/workspace/v044_gen`).
- 굽기: `scripts/v044_poses_build.py` — 두 행을 분리해 이어 붙여 12칸 스트립으로 만든다.
  - 행 사이 인물 크기 차이는 행 기준으로 보정하고, 프레임별로는 **부분 보정**(걷기·대기 k=1,
    공격·피격 k=0.6)해 웅크림·도약의 높이 변화는 남긴다.
  - 발(아래 12% 밴드)의 무게중심을 칸 중앙에 맞춰 몸이 흔들리지 않게 한다.
  - `uFx = 정수 프레임`, `uFs = 1/nf` 규칙 유지 — v0.42의 분신 겹침이 재발하지 않는다.
- **아우라 판은 절반 해상도**로 굽는다(부드러운 고리라 시각 차이가 없고 GPU 메모리가 1/4).
  → 프레임이 2배가 됐는데도 포즈 텍스처 총량은 v0.43보다 **작다**:
  v0.43 244MB(밉맵 포함 325MB) → v0.44 **231MB(308MB)**.

## 2. 재생 — 손그림 타이밍 곡선

12장을 균등 재생하면 오히려 기계처럼 보인다. 동작마다 프레임별 **머무름 가중치**(`ACT[].curve`)를 두어
기 모으기는 느리게, 베기는 빠르게, 여운은 느리게 흐르게 했다. 전체 길이는 v0.43과 같게 맞춰
게임 리듬(대시 0.28초 등)을 건드리지 않았다.

실측(1/60 스텝):
- idle 12칸 / 3.35초 순환
- walk 12칸 / 0.86초 순환(이동 거리에 묶임 — 속도가 변해도 발이 미끄러지지 않는다)
- slash 12칸 / 0.25초(전 프레임 재생)
- 원귀 walk 12칸 / 0.77초, attack 12칸 / 0.38초

## 3. 60fps 보간 (판 하나를 그대로 두고 몸을 산다)

- **전단 변형(uShear)**: 판의 아래(발)는 고정, 위로 갈수록 늦게 따라오는 2차 흔들림을 정점 셰이더에 넣었다.
  도포자락·머리카락이 프레임과 무관하게 60fps로 흔들린다(캐릭터별 세기 다름).
- **접지 스쿼시**: 발이 땅에 닿는 위상(위상 0·nf/2)에서 세로로 눌리고 가로로 퍼진다. 임계 감쇠 스프링.
- **종이 뒤집힘**: 좌우 반전을 0.12초 스무스스텝으로 — 판 폭이 0을 지나며 뒤집힌다(즉시 스냅 없음).
- **피격 반동**: 맞은 반대 방향으로 살짝 밀렸다가 제자리로.
- **무리 동기화 방지**: 적마다 걷기 위상(0~12프레임)·호흡 시계를 어긋나게 시작해 한 줄로 맞춰 걷지 않는다.

## 4. 검증

- 자산: 21개 동작 × 12칸 = 252칸 전수 검사 — **모든 칸에 인물 정확히 1개**, 좌우·상단 잘림 0
  (`reports/심안_v044_모션/ASSETS.json`).
- 프레임 궤적: idle/walk/slash/원귀 walk·attack 모두 12칸이 실제로 돈다(`GPv2.poseTrace`).
- 390×844 실플레이: 콘솔 에러 0 · 404 0, 캐릭터 양방향 정립(빌보드 축 기울기 ≈0).
- 제스처 510획 회귀: **PASS** (세로선→번개 0, 가로선→번개 0, 네모·탭 1.0, 기물 무늬 ≥0.55).
- CPU: 1인·1프레임 tick 0.0065ms (v0.43 0.005ms) — 45마리 기준 프레임당 +0.07ms(≈0.4%).
