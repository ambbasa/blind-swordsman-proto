# 심안 플레이 리뷰 — 2026-11-20

## 판단

가로획을 긋고 적을 베는 핵심 루프는 작동한다. 가장 먼저 고칠 부분은 콘텐츠 양이 아니라 **배울 곳에 들어갈 수 없는 문제**와 **그려야 할 무늬가 잘 보이지 않는 문제**다.

## 검토 방법

- 별도 로컬 주소의 새 저장 상태, 브라우저 390×844. 타이틀 → 1장 출전 → 일섬 → 마우스 드래그 네 번 → 일시정지 → 나가기. 성장·도감·설정·수련장도 일반 UI로 선택했다.
- 후반은 자연 해금이 아니라 QA 진입으로 분리했다. 1~12장 시작, 12장 보스 소환, 보스전 화면, 패배 화면과 다시 도전을 확인했다. 패턴 숙련도나 장별 클리어 난이도를 이 결과로 추정하지 않는다.
- 360×640 타이틀에서 버튼 좌표와 스크롤 범위를 측정했다. 휴대폰 화면 크기를 모사했지만 입력 기기와 오디오 출력은 실제 휴대폰이 아니다.

## 정상 동작과 측정의 한계

- 1장에서 실제 가로 드래그 후 HUD가 콤보 0 → 1 → 2 → 3으로 바뀌고 엽전·참이 증가했다. 정지 중 타이머 74초가 1.1초 동안 유지됐다.
- 성장·도감 열기/닫기, 타이틀 설정 펼치기, 패배 후 같은 장 재시작이 동작했다. 12개 장 모두 해당 이름으로 진입했다.
- 같은 세션 QA 연속 진입에서 동기 startRun은 6~14ms. 12장 보스전 안정 구간의 내장 FPS 표본 300개 평균은 약 60, 최저 약 57이었다. 새 기기 최초 실행·장 로딩 전체·실기기 성능·발열을 대표하지 않는다.
- 브라우저에서 WebGL 프로그램 조회 경고가 관찰됐다. 실제로 장 진입과 전투는 됐으므로 이를 렌더링 중단으로 판정하지 않았다. 다음에는 경고 발생 호출과 첫 프레임 손실을 함께 계측한다.
- 미검증: 실제 손가락 입력 정확도, 휴대폰 스피커에서의 종 방향 구분, 전 장 정상 해금·완주, 구매 후 장기 경제, 보스 전 패턴의 판정 일치. 이 항목은 재현된 결함과 분리한다.

## 추천 순서

수련장 이벤트 중복 → 안내 대비 → 작은 화면 출전 동선 → 전투·메뉴 상태 정리 → 보스 가독성 순으로 수정한다. 그 다음 새 플레이어에게 설명 없이 ‘연습장에서 반달을 익히고 보스 기물로 이동하기’를 맡겨, 메뉴 발견부터 실제 성공까지 어디에서 멈추는지 본다.
