# 실제 손 획 (아직 비어 있음)

설계안 v0.29 §2.3은 사람이 무늬마다 20번씩 그린 획을 저장해 합성 획과 함께 쓰라고 적었다.
이 폴더는 그 자리다. 지금은 비어 있고, 모이면 아래 형식으로 넣는다.

```json
[ { "shape": "vline", "who": "p1", "pts": [ {"x": 120, "y": 90}, {"x": 121, "y": 104} ] } ]
```

- `pts`는 QA 훅 `GPv2.strokePath(pts)`가 받는 것과 같은 화면 픽셀 좌표다.
- 파일 이름은 `real/<모으는 날짜>.json`. `tests/unit/gestures/run.py`가 있으면 함께 잰다.
- 개인정보(이름·연락처)는 적지 않는다. `who`는 p1, p2 같은 익명 표시만.
